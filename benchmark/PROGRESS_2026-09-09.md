# Conversion fidelity progress — September 9, 2026

The ten-app functional/usability goal is still open. Eleven pinned public
exports can be restored: the five `samples/real` apps and six Microsoft business
exports. All generate valid code. The five regression apps and Microsoft
Employee Ideas, Inspection and Milestones pass the short startup check. The
other three Microsoft apps fail startup, and those three clean startups fail
their Chromium first-action prerequisites. No fixture or clean loading screen
is counted as a usable real app.

The standard test command passes 208 Python tests and 76 JavaScript tests, with
three Python skips for unavailable local exports. The consistency gate checks
bare globals and actual callable FX/FXRuntime exports. Eight generated-fixture
browser journeys pass against generated Code.gs and a persistent Sheets test
double. This is not live Google authorization or production Sheets evidence.
Local cache entries are plaintext, browser-local and capped at 1 MB encoded.
Unidentified sessions share the app's cache in the same browser profile; known
users and separate deployed script IDs have separate namespaces. An Apps Script
page still requires network access, and browser settings can remove its cache.

Reproduce with Docker only:

```bash
./pfx2gas build
./pfx2gas test
./pfx2gas soak
./pfx2gas build browser
./pfx2gas browser
./pfx2gas browser scripts/assess_microsoft_samples.py
```

The last command is expected to fail while business-app blockers remain.
Artifacts are `.artifacts/benchmark/`, `.artifacts/microsoft/benchmark/` and
`.artifacts/browser/`. Browser records include input/converter hashes, console
errors, DOM measurements and screenshots. Converted screenshots are not
original Power Apps baselines. The five historical local exports, including
HelpDesk, are absent from this workspace and are not claimed as revalidated.

Implementation semantics were checked against Microsoft's

and [Power Fx grammar](https://learn.microsoft.com/en-us/power-platform/power-fx/expression-grammar).
The record work follows Microsoft's
[record scopes and disambiguation examples](https://learn.microsoft.com/en-us/power-platform/power-fx/tables),
[operators](https://learn.microsoft.com/en-us/power-platform/power-fx/operators), and

[If/Switch reference](https://learn.microsoft.com/en-us/power-platform/power-fx/reference/function-if).

[SaveData/LoadData/ClearData reference](https://learn.microsoft.com/en-us/power-platform/power-fx/reference/function-savedata-loaddata).

and [Power Fx data types](https://learn.microsoft.com/en-us/power-platform/power-fx/data-types).

[Acorn 8.15.0 parser](https://github.com/acornjs/acorn/tree/8.15.0).
